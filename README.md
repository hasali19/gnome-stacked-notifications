# gnome-stacked-notifications

Allows multiple notifications to be displayed in a stack in gnome shell.

## Install

```
mkdir -p ~/.local/share/gnome-shell/extensions
ln -s /path/to/repo ~/.local/share/gnome-shell/extensions/stacked-notifications@local
```

## Enable

```
gnome-extensions enable stacked-notifications@local
```

## Settings

```
gnome-extensions prefs stacked-notifications@local
```
