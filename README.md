# gnome-stacked-notifications

Allows multiple notifications to be displayed in a stack in gnome shell.

## Install

```
gnome-extensions install --force stacked-notifications@hasali.dev.shell-extension.zip
```

Might need to restart gnome shell before the extension can be enabled.

## Enable

```
gnome-extensions enable stacked-notifications@hasali.dev
```

## Settings

```
gnome-extensions prefs stacked-notifications@hasali.dev
```
